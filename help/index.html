Shu Desktop Pet — 使用说明

操作面板（屏幕上方浮动工具栏）

启动时自动出现，共 5 个按钮，顶部 ⋮⋮ 拖拽移动 ⋮⋮ 可拖到任意位置：

  • 互动 — 戳一下角色，它会做出攻击或技能反应，还会冒泡说话
  • 翻转 — 让角色左右转向，换个方向看
  • 动画 — 打开动画面板，查看/点播角色的各种动作（待机、攻击、技能等），支持循环播放
  • 设置 — 打开设置面板，搜索切换角色、选皮肤、选模型视角（正面/背面/基建）
  • 帮助 — 打开本页面

操作方式

模型缩放

Alt + 鼠标滚轮 — 放大缩小角色。

模型移动

Alt + 鼠标左键拖拽 — 把宠物拖到屏幕任意位置。

角色一直跟鼠标跑？

按一下 Alt 键就松开了。

Alt 操作没反应？ 说明鼠标没在交互区域内。
打开托盘菜单 → 「显示边界」，屏幕上会出现一个红框，红框范围内才是模型的有效交互区。

面板操作

  • 动画面板 / 设置面板：点击操作面板对应按钮打开，顶部拖拽条移动，再次点击按钮关闭
  • 操作面板：关掉后可从托盘菜单「显示/隐藏操作栏」重新打开
  • 面板位置会自动记住，拖到哪儿下次开还在那儿

退出程序

关闭窗口不会退出程序，它只是隐藏到系统托盘里了。
真正的退出：右键托盘图标 → 「退出」，或者托盘图标左键点一下显示窗口，再点关闭。

新角色发布

右键托盘图标 → 「检查角色更新」，有新干员会自动下载。

系统托盘（右键图标）

  • 显示/隐藏 — 切换窗口可见性
  • 置顶 — 是否总在最前面
  • 帧率 — 30/60 FPS 切换
  • 显示边界 — 显示红框（场景边界）和蓝框（交互区）
  • 显示/隐藏操作栏 — 开关操作面板
  • 使用说明 — 打开本页面
  • 检查角色更新 — 手动拉取新干员
  • 退出 — 唯一能真正退出的方式！
