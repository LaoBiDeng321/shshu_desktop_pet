# 对话总结：窗口鼠标穿透卡死 + 面板消失 + 模型吸附鼠标修复

> 日期：2026-07-22
> 问题：主窗口 Alt+拖拽后点击空白导致窗口不响应、面板点击空白概率消失、启动时模型吸附鼠标

---

## 1. Bug 1：主窗口鼠标穿透后卡死不恢复

### 现象

Alt+拖拽移动窗口后，点击空白区域，窗口永久不响应鼠标。Alt+Tab 可临时恢复。

### 根因

`setIgnoreMouseEvents(true, { forward: true })` 激活后，鼠标点击穿透到下层窗口 → 下层窗口激活 → 宠物窗口收不到 `pointermove` → 无法触发像素 alpha 检测恢复。唯一的恢复途径是键盘事件（Alt 键），解释了 Alt+Tab 能恢复的原因。

### 修复

在 `updateMouseIgnore` 设置 ignore=true 时，启动 `requestAnimationFrame` 轮询循环，通过主进程的 `screen.getCursorScreenPoint()` 获取全局鼠标位置，直接读取 WebGL `readPixelAlpha()` 检测光标下是否有模型像素。有则调用 `setIgnoreMouseEvents(false)` 恢复。

**修改文件**：
- `electron/main.ts`：新增 `get-cursor-pos` IPC handler
- `electron/preload.cjs`、`electron/preload.ts`：暴露 `getCursorPos` API
- `src/types/index.ts`：添加 `getCursorPos` 类型签名
- `src/features/pet/PetCanvas.vue`：新增 `startRecoveryPolling()` / `stopRecoveryPolling()` 轮询函数，在 `updateMouseIgnore`、`onContainerMouseLeave`、`onUnmounted` 中集成

## 2. Bug 2：面板子窗口点击空白后消失

### 现象

动画面板、设置面板点击空白区域有概率消失，操作面板也有类似问题。

### 根因

面板窗口使用 `transparent: true`，Windows 的 `WS_EX_LAYERED` + 逐像素 alpha 特性会将透明像素的鼠标事件**自动路由到下层窗口**。面板在主窗口上方 → 点击面板空白区域（透明像素） → OS 将事件传给下层的主窗口 → 主窗口的 `onInteractPointerDown()` 收到事件后主动隐藏了菜单/动画面板。

### 修复

移除 `onInteractPointerDown` 中的面板自动隐藏代码。面板现在仅通过操作面板按钮或面板自身的 `close` 事件管理。

**修改文件**：
- `src/features/pet/PetCanvas.vue`：删除 `showMenuPanel`/`showAnimPanel` 隐藏代码，添加注释说明

---

## 3. Bug 3：启动时模型吸附鼠标

### 现象

刚打开应用时，模型有概率"吸"在鼠标上，跟随鼠标移动（实际是窗口被拖拽）。

### 根因

`usePetDrag` 的 `onPointerDown()` 设置 `isDragging=true` 后，只靠 `pointerup` 事件重置。启动时的时序异常（模型加载中、焦点切换、浏览器 `pointercancel`）导致 `pointerup` 未触发，`isDragging` 卡在 `true`，后续每次 `pointermove` 都移动窗口。

### 修复

三处改动防御拖拽状态卡死：
1. `onPointerMove` 增加 `e.buttons === 0` 检查，无按钮按下时自动结束拖拽
2. 新增 `onPointerCancel` 处理系统取消指针捕获事件
3. `PetCanvas.vue` 绑定 `@pointercancel` 到交互层

**修改文件**：
- `src/features/pet/usePetDrag.ts`：`onPointerMove` 加 buttons 检查、新增 `onPointerCancel`、返回值暴露
- `src/features/pet/PetCanvas.vue`：模板绑定 `@pointercancel`、新增 `onInteractPointerCancel`、解构 `onDragPointerCancel`
